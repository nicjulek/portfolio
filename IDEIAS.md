# Ideias de portfólio com Three.js

1. **Mansão do Portfólio** (Blue Prince): planta azul; cada porta sorteia 3 cômodos; cada cômodo é uma seção. Meta: chegar à Antecâmara (contato).
2. **Sistema Solar em Loop** (Outer Wilds): planetas como áreas, fogueira central com "sobre mim", diário de bordo que se preenche, ciclo que reinicia.
3. **Reino Subterrâneo** (Hollow Knight): 2.5D, scroll desce camadas; mapa desenhado à mão conforme explora; bancos como checkpoints.
4. **Trilha na Floresta** (vibe Ghibli): árvore gigante, chuva, ponto de ônibus; câmera anda pela trilha; mascote original.
5. **Mesa Dividida**: metade estação de TI, metade prancheta; objetos clicáveis; terminal com comandos.

Stack: React Three Fiber, drei, GSAP, postprocessing, Rapier (opcional). Usar ilustrações próprias como texturas.
